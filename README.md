# Decentralized Audio Asset Management for Virtual Reality Entertainment

**Project ID:** 2602204  
**Team:** Team NOVACORE (Shourya Awasthi, Sakshi Yogi, Anany Mishra, Devesh Vashisht, Naveen Kumar Anand)  
**Institution:** K.R. Mangalam University (B.Tech CSE - Full Stack Development)  
**Faculty Mentor:** Dr. Pinki Kumari  

## Overview
A three-layer decentralized architecture designed to eliminate centralized server bottlenecks and deliver synchronized, tamper-evident audio for multi-user VR environments:
1. **Trust Layer (`AudioRegistry.sol`):** Ethereum smart contract storing SHA-256 audio hashes and WebTorrent identifiers for verifiable asset integrity.
2. **Distribution Layer (P2P Network):** Peer-to-peer chunk routing to scale bandwidth dynamically with audience size.
3. **Client Layer (`index.html`):** Browser-based Web Audio API player and spatial audio prototype.
